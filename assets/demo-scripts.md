# 演示录制用例

用于录制 README「效果演示」的 GIF。每个用例给出**可直接粘贴的提示词**、**预期画面**和**录制要点**。
录制前建议：`bun run dev` 启动，终端窗口尺寸调大些（侧栏 + 对话区都入镜）。

> 说明：跨会话记忆演示的是 **L2 `session_search`**（跨会话历史检索）。L1 Memory（memory.md / user.md）是**会话内**生效的，不跨会话；真正"跨会话找回细节"靠 L2。

---

## 用例 1：Todo List 生成（→ `assets/todo.gif`）

**目标**：让 Vivlos 为一个多步骤任务建立 Todo List，并逐项推进，侧栏实时刷新状态。

**粘贴提示词**：

```
帮我完成三件事，请先建立 Todo List 再逐项执行：
1. 统计 vivlos/agent 目录下 .ts 文件的数量
2. 找出所有引用了 EventBus 的文件并列出来
3. 读取 package.json，告诉我测试脚本命令是什么
每完成一项就更新 Todo 状态。
```

**预期画面**：
- 对话区出现 `todo_write` 工具调用，生成 3 条 Item
- 侧栏 TODO 区块出现，随执行逐条从 `○ pending` → `◉ in_progress` → `✓ completed`
- 每项执行时对应 Tool Call（bash / grep / read）滚动展示

**录制要点**：侧栏状态推进是重点，确保侧栏入镜；可从第一条 pending 录到最后全绿。

## 用例 2：子任务委派（→ `assets/delegation.gif`）

**目标**：让主模型经 `delegate` 工具并行派发一个 exploring + 一个 writing 子代理，展示委派卡片四阶段与钻取。

**粘贴提示词**：

```
请同时做两件互不依赖的事，并用 delegate 工具委派子代理并行处理：
1.（exploring）调查 vivlos 中上下文压缩的实现位置和触发条件
2.（writing）新建一个文件 delegation-demo-output.md，用中文写一段 150 字左右、
介绍"什么是子任务委派（subagent）以及它的好处"的说明文字
```

> writing 子任务是**新建文件**，不改动任何现有源码；录制完成后可删除 `delegation-demo-output.md`。

**预期画面**：
- 出现委派卡片：`正在规划任务…` → `已委派 2 个子任务`
- 两条任务行实时刷新（轮数 / 当前调用工具），`[Exploring]` 青色、`[Writing]` 橙色
- 完成后变 `✓`，显示轮数与耗时
- **点击任务行** → 钻取该子代理的会话对话；按 `↑` 返回主会话
- 侧栏 TASKS 区块出现两条任务

**录制要点**：卡片四阶段 + 钻取/返回是亮点；点击任务行那一下要录清楚。

## 用例 3：跨会话记忆（→ `assets/memory.gif`）

**目标**：在会话 A 留下一个独特细节，新建会话 B 后靠 `session_search` 把它找回来。

**步骤一 · 会话 A**（当前会话粘贴）：

```
我们定一个约定：vivlos 的演示视频统一放在 assets 目录，GIF 帧率用 15fps，
文件命名用小写中划线。记住这次讨论。
```

> 等它回复确认（可以顺带让它用 memory 存一条，但跨会话找回靠的是下面的 L2）。

**步骤二 · 新建会话**：`/new`（或界面上新建 Session），进入一个干净会话。

**步骤三 · 会话 B**（新会话粘贴）：

```
我们之前约定 vivlos 的演示 GIF 帧率用多少？文件命名规则是什么？
```

**预期画面**：
- 会话 B 中模型调用 `session_search`，命中会话 A 的那段讨论
- 回复里准确给出 `15fps`、`小写中划线命名`，并带来源锚点（来自哪个会话）

**录制要点**：要把"新建会话"这个动作录进去（证明是跨会话）；`session_search` 工具调用和带来源的回答是重点。

---

## 录制小贴士

- 每个用例录屏前 `/clear` 或新开会话，避免上一段干扰。
- 终端字体调大，GIF 宽度建议 ≥ 900px，帧率 10-15fps 控制体积。
- 委派用例耗时较长（子代理真实跑），可后期加速；Todo 和记忆用例较快可原速。
