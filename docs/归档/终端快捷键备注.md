# 快捷键注意事项

> [!CAUTION]
> 本文档为终端交互研究备注，已经归档，不作为当前快捷键清单。

## 终端 Ctrl+键 安全表

终端中 `Ctrl+字母` 会映射到 ASCII 控制字符。OpenTUI 的 `parseKeypress` 对部分控制字符有特殊处理，导致 **无法作为快捷键使用**。

### 不可用（被 parser 特殊处理，无法区分）

| 按键 | ASCII | parser 解析为 | 原因 |
|------|-------|-------------|------|
| Ctrl+A | 0x01 | `{ name: "a", ctrl: true }` | 部分终端保留为行首跳转 |
| Ctrl+C | 0x03 | `{ name: "c", ctrl: true }` | OpenTUI 特殊处理（exitOnCtrlC） |
| Ctrl+D | 0x04 | `{ name: "d", ctrl: true }` | 部分终端保留为 EOF |
| Ctrl+H | 0x08 | `{ name: "backspace" }` | 退格键 |
| Ctrl+I | 0x09 | `{ name: "tab" }` | Tab 键 |
| Ctrl+J | 0x0A | `{ name: "linefeed" }` | 换行键 |
| Ctrl+M | 0x0D | `{ name: "return", ctrl: false }` | 回车键，与 Enter 完全一致 |

### 可用（parser 正确解析为 `{ name: "x", ctrl: true }`）

```
Ctrl+B  Ctrl+E  Ctrl+F  Ctrl+G  Ctrl+K  Ctrl+L  Ctrl+N
Ctrl+O  Ctrl+P  Ctrl+Q  Ctrl+R  Ctrl+S  Ctrl+T  Ctrl+U
Ctrl+V  Ctrl+W  Ctrl+X  Ctrl+Y  Ctrl+Z
```

### 当前已分配

| 快捷键 | 功能 | 文件 |
|--------|------|------|
| Ctrl+L | 模型选择 | `commands/builtin/models.ts` |
| Ctrl+P | 供应商选择 | `commands/builtin/providers.ts` |
| Ctrl+O | 指令帮助 | `commands/builtin/help.ts` |

### 新增快捷键时

1. 从上方"可用"列表中选取
2. 避免与已分配的键冲突
3. 在此文件登记
