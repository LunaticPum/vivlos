# S4 L4 知识库规范

> **通俗解释**：L4 是用户自己维护的 Markdown 知识库（Vault，知识库目录），存放项目资料、研究笔记、领域文档等大块内容。Agent（智能体）不会每轮自动读写它，只有在明确的知识任务中（"把这份总结归档到知识库"、"查一下知识库里关于 X 的资料"）才通过专用 Skill（技能指引）访问。触发场景：用户显式要求整理或查阅知识库。首期实现最小读写与路径安全，不建索引。

## 1. Vault 形态

```text
<workspace>/.vivlos/vault/          # 默认 Vault Root，可在 config 覆盖
├── projects/
│   └── vivlos/
│       └── memory-design.md
├── notes/
│   └── 2026-08-04-调研.md
└── references/
    └── hermes-memory.md
```

- 内容为普通 Markdown 文件，用户可用编辑器与版本控制直接管理。
- 可选 frontmatter（`title` / `tags` / `updated`），首期只读取不强制。
- Vault 独立于 Session：删除 Session 不影响 Vault；删除 Vault 不影响 Session。

## 2. 访问入口

L4 只通过 `knowledge` Skill 暴露，不注册为常驻 Tool：

```text
用户提出知识任务
    │
    ▼
主模型加载 knowledge Skill（skill Tool）
    │
    ▼
Skill 指引模型调用 read / grep / write 等 builtin Tool
    │  （路径必须落在 Vault Root 内，由 VaultService 校验）
    ▼
Vault 文件
```

首期不新增专用 Tool：Skill 正文约束模型使用现有文件工具，并声明路径边界与确认规则。`VaultService` 作为程序化校验层，供后续专用 Tool 使用。

## 3. VaultService 契约

```ts
interface VaultService {
    readonly root: string;
    resolve(path: string): Result<string, VaultError>;   // 路径归一 + 包含校验
    search(query: string, limit?: number): VaultHit[];   // 文件名 + 内容关键词
    read(path: string, maxChars?: number): Result<string, VaultError>;
    write(path: string, content: string, opts: WriteOptions): Result<void, VaultError>;
    list(dir?: string): VaultEntry[];
}
```

路径策略（`path-policy.ts`）：

- 所有路径先 `resolve` 到 Vault Root，结果必须仍在 Root 内，否则拒绝。
- 拒绝符号链接指向 Root 外部的路径。
- 写入路径的父目录不存在时自动创建，但不允许逃出 Root。

## 4. 检索与注入

```mermaid
flowchart LR
    Q[模型需要知识] --> S[VaultService.search]
    S --> H[命中列表: 路径 + 匹配行]
    H --> R[VaultService.read 截断读取]
    R --> C[作为 Tool Result 进入当前 Context]
    C -->|值得长期保存| L1[重新调用 memory Tool 写 L1]
```

预算：

- `search` 最多返回 10 个命中，每个命中附带匹配行与前后各 2 行上下文。
- `read` 单次最多返回 8000 字符，超出截断并提示文件总长。
- 召回内容按 S0 规则包装为 `MemoryContextItem`（`layer: "l4"`），作为不可信数据处理。

## 5. 写入规则

- 写入仅发生在用户明确的知识整理任务中，Skill 正文必须要求模型先说明将写入的路径与内容摘要。
- 覆盖已有文件前必须先 `read` 确认现状；大段覆盖（>50% 原内容被替换）需要用户确认。
- 写入内容经过 `security.ts` 扫描（与 L1 共用），拒绝注入与凭证模式。
- L1 可以保存"详细资料见 vault:projects/vivlos/memory-design.md"这类短指针，但不复制 L4 全文。
