# Memory 模块文档

本目录是 Vivlos Memory（记忆）模块的开发规范集（Spec 即开发规范）。四层目标设计总览见 [记忆机制](../记忆机制.md)，本目录文档面向实现：定义每层做什么、何时触发、脚本如何组织、遵守哪份规范。

> 当前阶段以功能实现为目标，不追求生产级可靠性（原子写入、跨进程锁、崩溃恢复等不作为硬性要求）。

## 阅读顺序

1. 先读 [Memory 架构管线](./Memory架构管线.md)，建立脚本地图和依赖方向。
2. 再读 [S0](./S0-Memory公共约束.md)，所有层都必须满足的公共规则。
3. 按实现顺序读 S1 → S2 → S3 → S4。

## 实现顺序

```text
S0 公共约束与 Coordinator 骨架
  -> S1 L1 收紧（已实现，仅目录归位）
  -> S2 L2 完整实现（本阶段核心）
  -> S3 L3 契约 + 空实现
  -> S4 L4 契约 + 最小读写
```
