## 状态标记

文档使用以下标记区分设计与实现：

- **已实现**：当前源码已有完整或可用链路。
- **部分实现**：核心能力存在，但接口、UI 或可靠性仍不完整。
- **设计中**：目标架构已经明确，当前源码尚未实现。
- **占位**：目录或接口存在，但不应视为可用能力。
